# Lecciones — redactor-mensajes

Archivo donde se acumulan correcciones que Staff (Rafael) me hace a mensajes redactados. Cada entrada = una regla aprendida a partir de una corrección real.

**Formato de entrada:**

```
## YYYY-MM-DD — [regla en una línea]

- Intento: [mensaje original]
- Corrección: [mensaje corregido por Staff]
- Regla: [qué aprender]
- Destinatario: [Nancy / Don Titi / Félix / etc]
```
